# [채용공고] Harbor & Pine Commerce — 데이터 분석가 (신입)

> ⚠️ 실습용 가상 기업의 공고입니다.

## 회사 소개
Harbor & Pine Commerce는 한국과 동남아 3개국에서 온라인 쇼핑몰과 물류 서비스를 운영하는 가상의 이커머스 기업입니다.

## 주요 업무
- 주문·배송·고객 행동 데이터 분석과 대시보드 구축
- 물류 병목 구간 탐지와 개선안 제안
- **해외 물류 파트너와 영어로 지표를 공유하고 개선 사항을 협의**

## 자격 요건
- 통계·경영·산업공학 등 관련 전공 학사 이상
- SQL과 Python 기반 분석 경험
- OPIc IM1 이상 또는 이에 준하는 영어 말하기 능력

## 우대 사항
- 실제 업무 데이터로 지표 설계·개선 경험
- 분석 결과를 비전문가에게 설명해 의사결정으로 연결한 경험

## 전형 절차
1. 서류 → 2. 코딩·SQL 테스트 → 3. 1차 면접(직무) → 4. 2차 면접(영어 포함)

## 영어 면접 안내
- 2차 면접 중 약 8분은 영어로 진행됩니다.
- 질문 유형: 1분 자기소개 / 대표 분석 프로젝트 설명 / 데이터 해석이 팀원과 다를 때의 대응 / 지원 동기
- 평가 포인트: 유창함보다 분석 내용을 **정확하고 단순하게** 전달하는지
